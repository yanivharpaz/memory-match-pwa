# Memory Match

A responsive family-photo memory game that works as an installable PWA while remaining usable online without service-worker support. The browser code and layout support Safari 10 and iOS 10.3.

## Development

```sh
npm install
npm test
npm start
```

Source files live in `src/`; `dist/` is generated by `npm run build`. Original photos remain in `assets/`, and the build creates resized, metadata-free, versioned JPEGs for deployment.
