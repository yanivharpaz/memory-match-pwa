# Memory Match

A responsive family-photo memory game that works as an installable PWA while remaining usable online without service-worker support. The browser code, layout, and touch controls support Safari 10 on iOS 10.3.3. JavaScript is compiled to that browser target during every production build.

## Development

```sh
npm install
npm test
npm start
```

See [TESTING.md](TESTING.md) for the test architecture, complete case inventory, debugging guidance, and instructions for extending the suite.

Source files live in `src/`; `dist/` is generated by `npm run build`. Original photos remain in `assets/`, and the build creates resized, metadata-free, versioned JPEGs for deployment.
